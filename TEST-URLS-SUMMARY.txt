                          LOCAL TESTING (Development)
================================================================================

🏠 BASE URL: http://localhost:5000

📍 ENDPOINTS:

  ✅ Health Check
     GET http://localhost:5000/api/health
  
  ✅ Get All Users
     GET http://localhost:5000/api/users
  
  ✅ Get User by ID
     GET http://localhost:5000/api/users/1
  
  ✅ Create User
     POST http://localhost:5000/api/users
     Body: {"name":"John Doe","email":"john@example.com"}
  
  ✅ Update User
     PUT http://localhost:5000/api/users/1
     Body: {"name":"John Updated","email":"john.updated@example.com"}
  
  ✅ Delete User
     DELETE http://localhost:5000/api/users/1

================================================================================
                            HOW TO USE
================================================================================

LOCAL TESTING:
1. Start the API:
   cd /path/to/hackathon
   dotnet run

2. Test in browser:
   Open: http://localhost:5000/swagger

3. Test with curl:
   curl http://localhost:5000/api/health

APIM TESTING (After Deployment):
1. Find your APIM service name in Azure Portal or GitHub secrets

2. Replace {your-apim-service} with actual name, e.g.:
   https://my-apim-service.azure-api.net/sample-api/api/health

3. Test with curl:
   curl https://my-apim-service.azure-api.net/sample-api/api/health
